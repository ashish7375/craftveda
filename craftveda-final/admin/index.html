Sign in with your GitHub repository and access token. They stay only in this browser.

How to get the token (2 minutes)
  1. GitHub > your profile picture > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
  2. Repository access: Only select repositories > choose your craftveda repository.
  3. Permissions > Repository permissions > Contents: Read and write.
  4. Generate and copy the token. Paste it here.
